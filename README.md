## 🚀 Getting Started

1.  **Clone or Download**: Clone this repository or download the specific `workflow.json` you need.
2.  **Import to n8n**:
    - Open your n8n instance.
    - Go to **Workflows** > **Add Workflow**.
    - Click the menu (three dots) > **Import from File**.
    - Select the `workflow.json` file.
3.  **Configure Credentials**: Update the credential nodes with your own API keys as specified in the workflow's local `README.md`.
4.  **Activate**: Toggle the workflow to Active.
